# Aprendiendo Optimización Lineal

Aplicación web progresiva (PWA) para aprender optimización lineal paso a paso.

## Estructura
- index.html: aplicación completa
- manifest.json: configuración para instalar como app
- service-worker.js: modo offline
- icons/: íconos de la app

## Cómo publicar en GitHub Pages
1. Sube estos archivos sueltos a la raíz del repositorio.
2. En Settings > Pages, selecciona Deploy from a branch.
3. Branch: main / root.
4. Espera el despliegue y abre el link.

## Cómo actualizar
Reemplaza index.html, manifest.json, service-worker.js e icons/ en el repositorio y haz commit.
