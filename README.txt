Aprendiendo Optimización Lineal - versión profesor v3

Cambios principales:
- Curso separado por páginas: explicación, ejercicios explicados, práctica guiada y ejercicios libres.
- Mayor desarrollo visual: tablas, matrices, gráficos en canvas, árbol de Branch and Bound.
- Ejercicios explicados paso a paso: Vogel, MODI, Simplex Dual, Húngaro, método gráfico, formulación.
- Práctica guiada con corrección paso a paso.
- Ejercicios libres con área de desarrollo, guardado local, pistas y soluciones.

Publicación:
1. Descomprime el ZIP.
2. Sube index.html, manifest.json, service-worker.js, README.txt e icons/ a la raíz del repositorio.
3. Haz commit y espera GitHub Pages.
4. Si aparece una versión antigua, usa Ctrl+F5 o borra la app instalada y vuelve a agregarla.
