Aprendiendo Optimización Lineal

Aplicación web progresiva (PWA) para estudiar optimización lineal.

Archivos principales:
- index.html: entrada de la aplicación.
- styles.css: diseño.
- app.js: contenido, interacción, progreso y quiz.
- manifest.json: configuración para instalar como app.
- service-worker.js: funcionamiento offline.
- icons/: íconos.

Publicación en GitHub Pages:
1. Sube todos estos archivos sueltos a la raíz del repositorio.
2. En Settings > Pages selecciona Deploy from a branch.
3. Branch: main. Carpeta: /(root).
4. Guarda y espera el despliegue.

Actualizar:
- Reemplaza archivos en el repositorio.
- Haz Commit changes.
- Espera a que GitHub Pages termine.
- Si el navegador muestra versión antigua, usa Ctrl+F5 o borra caché/app instalada.
